# osrs_hiscore_pull Council

This directory contains the council configuration for **osrs_hiscore_pull**.

## What is `.council/`?

The `.council/` directory defines your agent roster and customizations for [Claude Code](https://claude.ai/claude-code). When you run `council update`, it generates:

- **Claude prompts** → `.claude/agents/[agent].md` (agent personas and instructions)
- **CLAUDE.md** → `.claude/CLAUDE.md` (project instructions)
- **Rules** → `.claude/rules/*.md` (behavioral constraints)

## Directory Structure

## Quick Start

### 1. Customize Your Roster

Edit `roster.yaml` to add, remove, or modify agents:

```yaml
defaults:
  model: sonnet           # Default model for agents
  council_role: specialist

agents:
  - name: atlas
    display_name: Atlas
    title: System Orchestrator
    description: Coordinates the council
    model: inherit        # Use parent council's model
    council_role: coordinator
    domains:
      - orchestration
      - coordination
```

**Valid `model` values:** `haiku`, `sonnet`, `opus`, `inherit` (inherits from parent council)

**Valid `council_role` values:** `coordinator`, `specialist`, `auditor`, `omniscient`

### 2. Generate Claude Files

After editing `roster.yaml`, run:

```bash
council update --dry-run   # Preview changes
council update             # Apply changes
```

This regenerates all `.claude/` files from your roster.

### 3. Add Custom Agents

To add a new agent, append to `roster.yaml`:

```yaml
agents:
  # ... existing agents ...

  - name: myagent
    display_name: MyAgent
    title: Custom Agent Title
    description: What this agent does
    domains:
      - domain-one
      - domain-two
    disallowed_tools:     # Optional: restrict tool access
      - Write
      - Edit
    custom_sections:      # Optional: inject custom content
      expertise: |
        ## My Custom Expertise

        Additional instructions here...
```

Then run `council update` to generate `.claude/agents/myagent.md`.

## Advanced Customization

### Override Templates

To customize how agents are generated, place a file with the **same name** in `.council/templates/`:

```bash
# Copy default template
cp /home/austin/projects/runescape/osrs_hiscore_pull/src/council_mcp/agents/templates/agent_card.md.j2 .council/templates/

# Edit your copy
vim .council/templates/agent_card.md.j2

# Regenerate (your template will be used)
council update
```

### Custom Sections

Use `custom_sections` in `roster.yaml` to inject additional content into agent prompts:

```yaml
- name: forge
  custom_sections:
    tools: |
      ## Custom Tools

      You have access to specialized forge tools...

    examples: |
      ## Examples

      Here's how to use forge...
```

Sections are injected into the agent template at `{{ custom_sections.section_name }}`.

### Disable Tools

Restrict specific tools per agent using `disallowed_tools`:

```yaml
- name: lens
  disallowed_tools:
    - Write       # Research agent can't write files
    - Edit        # Research agent can't edit files
    - Bash        # Research agent can't run shell commands
```
